# AlumniConnect — React Alumni Career Mentorship & Networking

A polished, responsive React + Vite frontend for an alumni career platform.

## Features

- Modern responsive dashboard
- Alumni/mentor directory with match scores
- Mentor connection flow
- Events calendar and registration
- Create/publish event modal
- Jobs & internships board
- Save opportunities
- Alumni community feed
- Trending topics and community guidelines
- Student profile page
- Search across the experience
- Notifications/toast feedback
- Dark/light mode
- Responsive mobile navigation
- GitHub-ready project structure

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Build

```bash
npm run build
```

## Suggested production upgrades

This project is intentionally frontend-first. For a production version, connect:
- Firebase/Supabase for authentication and database
- Cloudinary/S3 for event/profile image uploads
- WebSockets/Firebase for real-time chat
- Email/calendar APIs for event reminders
- Role-based admin permissions
- Real mentor recommendation algorithm
- Payment integration for paid events
