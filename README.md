📌 About the Project

The Alumni Career Mentorship Platform is a web-based project designed to connect students with alumni for career guidance, mentorship, industry insights, and professional development.

The goal is to help students explore career opportunities, gain valuable knowledge from experienced professionals, and build meaningful professional connections.
